# Wird (وِرْد) — Premium Islamic Dhikr Counter 📿

An ultra-premium, minimalist, and offline-first Islamic Dhikr and Astaghfar counter. Designed for the elite top 1% user experience, focusing entirely on spirituality, focus, and simplicity without any modern-day distractions.

## ✨ Core Philosophy
- **Zero Ads:** Worship should not be monetized.
- **Zero Distractions:** No leaderboards, no gamification, no spam notifications.
- **Zero Dependencies:** Built with pure Vanilla HTML/CSS/JS. Extremely lightweight (< 50KB).

## 🚀 Elite Features
- **True Active Timer:** Tracks only real active dhikr time. Pauses instantly when idle.
- **Physical Haptics:** 30ms crisp vibration patterns that mimic the feel of real wooden tasbeeh beads.
- **Wooden Audio Engine:** Web Audio API generated wooden "thock" sound (0 bytes extra storage).
- **Breathing Invite:** Subtle breathing animations to gently invite you to start your dhikr.
- **Golden Hour:** Visual ambient cue 1 hour before the Tahajjud rollover to save your daily streak.
- **100% Offline (PWA):** Installable on any device. Works completely offline via Service Workers.

## 📊 Deep Analytics & Stats
- **30-Day Heatmap Calendar:** Visual representation of your daily consistency.
- **Weekly Progress Bars:** Compare your current week's ibadah with the last 3 weeks.
- **Grand Totals & Streaks:** Tracks lifetime milestones across all 5 authentic dhikr modes.

## 🛠️ Technical Stack
- **Frontend:** Pure HTML5, CSS3, Vanilla JavaScript (ES5/ES6)
- **Storage:** LocalStorage API (Data never leaves your device)
- **PWA:** Fully compliant Manifest & Service Worker for native Android/iOS installation
- **Design:** CSS Variables, Radial Gradients, Safe-area insets for modern notch displays.
